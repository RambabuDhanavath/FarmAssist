# FarmAssist

> A web application designed to provide assistance and resources to farmers — helping them improve agricultural practices, increase productivity, and enhance their livelihoods.

## Problem

Farmers often lack easy access to timely, relevant information about crop management, weather, market prices, and government schemes. FarmAssist centralizes these resources in one friendly web app.

## Features

- 🌾 **Crop guidance** — best practices for planting, irrigation, and pest control
- ☀️ **Weather-aware planning** — plan sowing and harvesting around local conditions
- 💰 **Market prices** — track commodity prices to sell at the right time
- 📚 **Resource library** — articles and guides on modern agricultural practices
- 📢 **Government schemes** — discover subsidies and programs available to farmers
- 📱 **Responsive design** — works on phones, tablets, and desktops

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript (responsive design)
- **Planned:** REST API backend, database-backed content

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/RambabuDhanavath/FarmAssist.git
   cd FarmAssist
   ```

2. Open `index.html` in your browser, or serve it locally:

   ```bash
   npx serve .
   ```
